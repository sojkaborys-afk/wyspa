# Wyspa 🏝️

**Wyspa** to pastylka u góry ekranu w stylu Dynamic Island z uroczym stworkiem **Bąblem**. Klikasz, a rozwija się panel z szybkimi akcjami, muzyką, narzędziami, grami i czatem po polsku. Za darmo, wszystkie funkcje.

👉 **Strona i pobieranie: https://wyspa-app.pages.dev**

Wszystkie wersje: [Releases](https://github.com/sojkaborys-afk/wyspa/releases). Sumy kontrolne są w pliku `SHA256SUMS` przy każdym wydaniu.

## Dobrze wiedzieć
- **Windows:** instalator nie jest jeszcze podpisany. Jeśli SmartScreen ostrzeże, kliknij **Więcej informacji** → **Uruchom mimo to**.
- **Android:** aplikacji nie ma jeszcze w Sklepie Play. Zezwól na instalację z tego źródła, gdy telefon zapyta.
- **Mac:** to wersja testowa, niepodpisana. Pierwsze otwarcie: prawy przycisk → **Otwórz**.

To repozytorium służy tylko do udostępniania plików do pobrania. Kodu źródłowego tu nie ma.
